# صيغة تغريدة طويلة عن نقاء

أطلقت برنامج **نقاء** لويندوز: أداة محمولة بملف واحد، بدون تثبيت، هدفها تنظيف الجهاز بعمق وإزالة البرامج ومخلفاتها بطريقة أوضح وأكثر تحكمًا.

نقاء لا يكتفي بتشغيل مزيل التثبيت الرسمي للبرنامج. بعد الإزالة يقدر يفحص البقايا المرتبطة بالتطبيق مثل المجلدات، الكاش، بعض آثار Registry، والمسارات المتروكة، ثم يعرضها للمراجعة ويعزلها بدل حذفها مباشرة حتى تقدر تسترجعها عند الحاجة.

أبرز ما يقدمه:

- عرض البرامج المثبتة مع الحجم، الناشر، الإصدار، تاريخ التثبيت، والمسار.
- ترتيب حسب الاسم، الحجم، الناشر، الإصدار، وآخر تثبيت.
- بحث سريع داخل البرامج.
- تنظيف كاش الجهاز من مسارات متعددة.
- عزل المخلفات مع خيار استرجاع آخر عزل.
- قناص بدء التشغيل لتقييم عناصر Startup بدرجة خطورة وشرح تقني للسبب.
- مراقبة الاتصالات الحالية وربطها بالعمليات.
- فحص DNS Cache وملف Hosts وبعض آثار النظام.
- مراقبة تثبيت البرامج عبر مقارنة Snapshot قبل وبعد.
- تقرير صحة شامل بنقرة واحدة.
- اكتشاف تحديثات التطبيقات عبر winget عند توفره.
- فحص أمان محلي يعتمد على مؤشرات سلوكية مثل السكربتات المشبوهة، المسارات الخطرة، الاستدعاءات الحساسة، والملفات عالية الغموض.
- وضع شريط النظام: إذا أغلقت النافذة يبقى البرنامج يعمل بجانب الساعة مثل التطبيقات الاحترافية.
- تنبيهات أذكار وأدعية عشوائية أثناء عمله بالخلفية.
- واجهة عربية بالكامل مع دعم الإنجليزية.

تنبيه مهم: نقاء ليس بديلًا عن مضاد فيروسات كامل، لكنه يعطيك طبقة فحص ومراجعة محلية تساعدك تفهم ما يحدث في جهازك وتكتشف العناصر التي تستحق الانتباه.

البرنامج موجه للاستخدام الشخصي، وفكرته الأساسية: تنظيف أوضح، تحكم أكبر، وتقارير تساعدك تعرف ماذا تم حذفه أو عزله بدل تنفيذ عمليات عمياء.
