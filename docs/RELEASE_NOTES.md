# نقاء 1.0.0

## عربي

الإصدار الأول من نقاء يقدم نسخة محمولة لويندوز تجمع بين إزالة البرامج، تنظيف المخلفات والكاش، مراقبة بدء التشغيل، الفحص الأمني المحلي، تقارير الصحة، وتنبيهات الأذكار.

أهم الإضافات:

- نسخة محمولة بملف EXE واحد.
- واجهة عربية مع دعم الإنجليزية.
- قائمة برامج قابلة للبحث والترتيب.
- عرض الحجم، الناشر، الإصدار، تاريخ التثبيت، والمسار.
- فحص بقايا البرامج وعزلها.
- تنظيف كاش الجهاز.
- قناص بدء التشغيل مع تقييم خطورة.
- فحص سلوكيات مشبوهة محليًا.
- مراقبة الاتصالات وDNS وSnapshots.
- وضع System Tray عند إغلاق النافذة.
- تنبيهات أذكار وأدعية عشوائية من الخلفية.

## English

Niqaa 1.0.0 is the first portable Windows release combining deep uninstall support, leftover cleanup, cache cleaning, startup inspection, local heuristic security checks, health reports, and background dhikr notifications.

Highlights:

- One-file portable EXE.
- Arabic interface with English support.
- Searchable and sortable installed app list.
- App size, publisher, version, install date, and path display.
- Leftover scanning and quarantine.
- Device cache cleanup.
- Startup Hunter with risk scoring.
- Local suspicious behavior checks.
- Connection, DNS, and snapshot monitoring.
- System tray mode when the window is closed.
- Random dhikr and dua notifications while running in the background.
